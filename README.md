## Glosario

### Parte 1

#### Algoritmo

Un algoritmo es una secuencia ordenada, precisa, finita y legible de pasos diseñados para resolver un problema mediante tres fases: Entrada, Proceso y Salida.

*Ejemplo:* Un ejemplo de un algoritmo sería el seguir los pasos de cómo hacer un sándwich de queso.

#### Programa

Se refiere a un conjunto de instrucciones suficientemente claras para que una computadora las pueda entender y ejecutar sin preguntar nada (Específico).

*Ejemplo:* Un ejemplo de un programa es el `print("Bienvenido a Teams.")`.

#### Código Fuente

Un conjunto de instrucciones redactadas en un lenguaje de programación que le informan al programa cómo debe comportarse o, en otras palabras, es un plano para que se ejecute.

*Ejemplo:* `print("Bienvenido a Teams.")`

#### Lenguaje de programación

Se puede referir como un conjunto de reglas gramaticales que permiten a un programador escribir una serie de comandos e instrucciones escritas en datos y actividades específicas que controlan el comportamiento físico y lógico de un dispositivo (Computadora).

*Ejemplo:* Un ejemplo de lenguaje de programación es Python.

#### Sintaxis

En programación se refiere al conjunto de reglas y principios que rigen la estructura, orden y forma correcta de escribir los símbolos, palabras y puntuación en el lenguaje de programación.

*Ejemplo:* Sintaxis correcta sería `print("Hola, mundo")`.

#### Variable

Espacios donde se almacenan datos que el programa utilizará durante su ejecución. Pueden ser letras, números y el símbolo.

*Ejemplo:* `nombre = "Arturo"`

#### Constante

Una constante es un valor fijo que está fijo durante la ejecución del programa. A diferencia de una variable, una vez que se le asigna un valor, éste tiene permanencia. Usualmente van EN MAYÚSCULAS para identificarlas fácilmente en el código.

*Ejemplo:* $PI = 3.1416$ (Python)

#### Tipo de dato

Un tipo de dato es un atributo que le indica al equipo la naturaleza de los datos que va a procesar. Define el conjunto de valores posibles que puede tomar una variable o constante, y las operaciones que se pueden realizar con ellos.

*Ejemplo:* Un ejemplo de un tipo de datos sería el entero ($90$) o los reales ($2,5$, etc.).

#### Operador

Los operadores son símbolos o palabras especiales que se utilizan para realizar operaciones sobre datos (llamados operandos). Permiten manipular, transformar o comparar valores en un programa. Los operandos son los valores (variables, constantes o literales) sobre los que actúa el operador.

*Ejemplo:* Hay varios tipos de operador como: módulo, mayor que, diferencia, suma, etc.

#### Expresión

Una expresión es un conjunto de operandos y operadores que, al ser evaluados, producen un resultado determinado (Valor). Por ejemplo, sabiendo que es un conjunto de operandos y operadores, podemos pensar en la expresión $6 + 7$ que da como resultado $13$.

#### Condicional

Los condicionales son estructuras de control que permiten al programa tomar decisiones. Evalúan una condición (verdadera o falsa) y, según el resultado, ejecutan un bloque de código u otro.

*Ejemplo:* En algoritmo natural sería algo como escribir:

> Inicio, leer $a$, leer $b$, $p - a + b$, $¿p = 10?$, Si sí igual, Si no Diferente.

#### Bucle

Un bucle (también llamado ciclo o loop) es una estructura de control que permite repetir un bloque de código varias veces de forma automática, mientras se cumpla una condición determinada.

*Ejemplo de Bucle en Python:*

```
for i in range(1, 6):
    pass

```

#### Función

Una función es un bloque de código reutilizable que realiza una tarea específica.

*Ejemplo de una función:*

```
total = sumar(8, 5)  # 8 y 5 son argumentos
print(total)         # Imprime: 13

```

#### Parámetro

Un parámetro es un dato de entrada que se le entrega a una función para que lo procese y pueda realizar su tarea. De manera más simple, funciona como la información que necesita el código para poder trabajar y devolver un resultado.

*Ejemplo:* En una suma, por ejemplo, $a$ y $b$ son necesarios para que pueda suceder una suma.

#### Argumento

El argumento es el dato de entrada que viaja hacia el parámetro cuando ejecutas una función; así se puede entender que es el valor real y específico que se le proporciona a una función cuando esta es llamada o ejecutada. Con el ejemplo anterior, sería cuando se utilizan valores concretos para que la suma se vea así: $5 + 4$.

#### Retorno

El valor de retorno de una función es el resultado final u output que esta entrega tras procesar los datos. Funciona como la respuesta que la función envía de vuelta al código principal para que pueda ser utilizada, almacenada o evaluada en otra parte del programa.

*Ejemplo:* Por ejemplo de $5 + 4$ el retorno sería $9$.

#### Arreglo

La definición es la de un tipo de dato que almacena un conjunto ordenado de elementos del mismo tipo dentro de una sola variable.

*Ejemplo:* Se puede considerar un arreglo los días de la semana:

```
dias_semana = ["Lunes", "Martes", "Miércoles", "Jueves", "Viernes"]

```

Ya que existe el conjunto de los cinco días dentro de esta.

#### Objeto

Un objeto es una unidad que al agrupar datos y funciones logra representar elementos del mundo real.

*Ejemplo:* Un objeto puede ser un celular, teniendo así los datos como el color, la marca, etc.

#### Método

Es una función que, al pertenecer a un objeto o clase, define lo que ese objeto puede hacer (su comportamiento) y, por lo general, interactúa, modifica o trabaja con los datos internos almacenados dentro de dicho objeto.

*Ejemplo:* Con el ejemplo del celular, un método podría ser el cambiar de pestaña o hacer una llamada.

#### Evento

Es una acción o señal específica que ocurre durante la ejecución de un programa, a la cual el código puede reaccionar. Es decir: cuando ocurre esto, sucede aquello en consecuencia.

*Ejemplo:* Un ejemplo de esto sería presionar nuestro espacio o teclas que envían información a la computadora.

### Parte 2

#### Compilador

Programa que se encarga de traducir el código fuente escrito por un programador a lenguaje binario para que las máquinas lo puedan entender. Primero lo procesa y después lo traduce.

*Ejemplo:* Un ejemplo de compilador sería Javac para Java.

#### Intérprete

Lee, analiza, traduce y ejecuta el código línea por línea en tiempo real.

*Ejemplo:* Un ejemplo de un intérprete es Python (el programa).

#### Depurador (Debugger)

Programa informático especializado que permite a los desarrolladores monitorear, inspeccionar y controlar la ejecución de otro software en tiempo real con el objetivo de identificar, rastrear y corregir errores (bugs) dentro del código.

*Ejemplo:* PDB (Python Debugger) viene integrado en Python y es un ejemplo de Debugger.

#### IDE (Integrated Development Environment)

El IDE reúne todas estas herramientas en una sola ventana (un editor de texto por un lado, un ejecutable para compilar por otro y un debugger externo). Bien así, se puede definir como una aplicación de software que reúne un conjunto de herramientas combinadas en una sola interfaz.

*Ejemplo:* Un ejemplo de eso es Visual Studio Code.

#### Editor de código

Aplicación de software diseñada específicamente para escribir y modificar código fuente, está optimizado para interpretar la sintaxis de lenguajes de programación mediante características como resaltado de color, autocompletado y formato estructurado.

*Ejemplo:* Un ejemplo de esto es VS Code (no confundir con Visual Studio, que es un IDE).

#### Biblioteca (Library)

Se puede definir como el conjunto de código reutilizable previamente escrito (funciones, clases, variables o estructuras) incorporable dentro de otros programas para resolver tareas comunes sin tener que escribir el código desde los cimientos.

*Ejemplo:* Un ejemplo de biblioteca sería OpenCV.

#### Framework

De manera básica se le conoce como el "esqueleto" sobre el cual se construye una aplicación. En otras palabras, es una plantilla para guiar y estandarizar el desarrollo de software.

*Ejemplo:* Un ejemplo de esto sería el framework conocido como Design thinking.

#### API (Application Programming Interface)

Es una interfaz compuesta por conjunto de reglas, protocolos y definiciones que permiten la comunicación de aplicaciones. Permite integrar información de otras aplicaciones y no iniciar desde cero.

*Ejemplo:* Un ejemplo de una API sería el "Iniciar sesión" de Google.

#### Repositorio

Funciona como una estructura o espacio de almacenamiento digital centralizado que los desarrolladores utilizan para guardar, gestionar, rastrear cambios y colaborar en el código fuente de un proyecto de software. Puede ser privado o público (compartir tu proyecto con otras personas).

*Ejemplo:* Un ejemplo sería mi propio repositorio de apuntes para la clase de álgebra y se encuentra en GitHub.

#### Control de versiones

Es un sistema que registra los cambios realizados en un archivo o conjunto de archivos a lo largo del tiempo, de modo que puedas recuperar versiones específicas más adelante.

*Ejemplo:* En Visual Studio Code se puede realizar usando el comando `git` seguido de `git commit` para guardar cambios y finalizar con el `push` para guardar el cambio dentro de GitHub.

#### Git

Es una herramienta de software ejecutable cuya función es la de rastrear cambios en el código fuente durante el desarrollo de software lo que permite gestionar proyectos con eficacia.

*Ejemplo:* Git es un ejemplo de sistema de control de versiones.

#### GitHub

Es una plataforma que permite almacenar proyectos en la nube que utiliza el sistema de guardados conocido como Git. Permite la colaboración de diferentes personas dentro de un mismo código al actuar como una red social entre programadores.

*Ejemplo:* Un ejemplo de cómo usar GitHub sería al crear un repositorio e irlo actualizando con el tiempo mientras tu proyecto avance.

#### Rama (Branch)

Es útil para probar ideas arriesgadas o evitar errores dentro del código principal, es decir, es algo independiente al principal y crear nuevas cosas en un ambiente aislado.

*Ejemplo:* Un ejemplo de esto podría ser en Visual Studio Code donde utilizamos el comando `git branch nombre_de_la_rama`.

#### Commit

Es similar a tomar una captura de pantalla de tu trabajo, es decir, una manera de guardar permanentemente un conjunto de cambios en el historial del repositorio.

*Ejemplo:* En Visual Studio Code se realiza un commit haciendo `git commit -m "x"` para guardarlo en tu repositorio.

#### Merge

Básicamente sirve para combinar los cambios de una rama hacia otra, es decir, integra cambios y commits hacia otra rama.

*Ejemplo:* En la rama principal (`main`) puedes ejecutar `git merge rama_secundaria` para introducir cambios que no querías arriesgar pero terminaron siendo favorables.

#### Callback

Es una función que sirve para indicar que algo suceda después de determinado evento, para que ocurra en un momento específico.

*Ejemplo:* Cuando el usuario haga clic ocurrirá una función.

#### Programación síncrona

Se refiere a un tipo de función que básicamente sirve para emplear un orden estricto en la cadena de operaciones de un programa. A diferencia de la asincrónica, esta puede terminar ralentizando las cosas y causar retrasos. Este tipo de programación es particularmente efectiva para efectuar procesos matemáticos, los cuales requieren un orden estricto a la hora de ser ejecutados.

#### Programación asíncrona

Se refiere a un tipo de función especial que sirve para ejecutar tareas en segundo plano sin ralentizar, lo cual significa que son particularmente útiles con operaciones que pueden tardar mucho en completarse.

*Ejemplo:* Es similar a poner un bloque de respuesta a un evento para que cuando ocurra, los procesos sigan su camino sin tener que congelar el resto de las operaciones.

#### JavaScript

Es un lenguaje de programación especialmente útil para agregar interactividad en tiempo real (animaciones, actualizaciones, etc.). Se le puede ver como los botones que hacen que ocurran determinadas reacciones a situaciones ocasionadas por un usuario.

*Ejemplo:* Un formulario para iniciar sesión el cual debe responder en tiempo real sin tener la necesidad de recargar la página manualmente.

#### TypeScript

Este se construye directamente sobre la base de JavaScript, sin embargo, TypeScript agrega nuevas funcionalidades al anterior para tener la habilidad de verificar errores al costo de que los navegadores no lo puedan entender directamente al compilar todos los datos para JavaScript.

*Ejemplo:* Datos que informan de errores antes de ejecutar un programa para poder corregirlos.
